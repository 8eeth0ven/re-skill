# 打穿短表:桌面与生态(子表)

> 主索引见 `../打穿短表-CVE.md`,本表专收桌面软件与生态供应链面。四列同主表:`认什么|打哪|出什么算成|假点`。环境可行性卡壳先查 `../从逆向到CVE-能力审计.md`(C 分支 Windows 用户态/F 行浏览器);报送环节跳 `../漏洞披露与CVE申请.md`。表上没有的面照样挖。

| 认什么 | 打哪 | 出什么算成 | 假点 |
| --- | --- | --- | --- |
| Electron 桌面 app:注册自定义协议(`setAsDefaultProtocolClient`/manifest `protocol`s 项) | 外部网页拉起 `app://`/`myapp://` 带 `../`、`%00`、二次编码参数→看协议 handler 是否直接把参数喂 `loadURL`/`shell.openPath`/`BrowserWindow`;核对 `nodeIntegration`/`contextIsolation`/`sandbox` 三开关;`webSecurity` 有没有关 | 默认配置下网页拉起即本地文件读/Node 侧 RCE(影响所有安装用户,不用诱骗改配置) | 需用户手动开不安全开关才算;协议参数只进自家白名单路由;devtools 遗留不算 |
| Electron preload/contextBridge 暴露面:bridge 把 fs/shell/child_process 包一层暴露给页面 | `npx asar extract` 解包读 preload JS;contextBridge 暴露函数的参数是否直接拼路径/命令(路径穿越 `..\\`);页面内容来源核对(是否加载远程页/iframe) | 页面 XSS 或所加载远程站→bridge 调任意文件写/命令执行 | bridge 参数全枚举白名单;页面全离线无远程内容 |
| CEF 桌面 app:`node_integration` 遗留/命令行 flag 转发;CEF 版本停在老分支 | 查编译配置与进程命令行(外部输入能不能进 `--` 参数);JS 注入面(表单/富文本/webview)探 `window.require/process`;`remote-debugging-port` 遗留口(127 直连) | 渲染面 JS 到 Node 侧 RCE;或无鉴权调试口可注入任意页面脚本 | node 集成明确关闭;调试口绑 127 且带随机 token;flag 只来自本地配置文件(无外部输入) |
| WebView2 桌面 app(Edge 运行时共享):Fixed Version 分发不自更新 | 确认运行时策略(Evergreen 自更新/Fixed 锁死);Fixed 版本号对照同期 Edge 安全公告是否带洞;`AddWebResourceRequested`/`WebResourceRequested` 过滤器绕过(scheme 大小写/尾斜杠);`postMessage` 桥 native 侧解析 | 同 Edge 已修洞在 app 内可触发(影响面=app 全量用户),或桥消息直达 native 命令拼接 | Evergreen 自动更新版本差不存在;洞只影响浏览器进程模型不适用 WebView2 |
| 桌面 app 内嵌更新器:更新包校验弱(只比长度/哈希,或走 http) | 抓更新检查请求;看校验逻辑顺序(先装后验=没用);签名校验绕过(哈希随包走/签名只在公告页);差分更新包(bsdiff/自研)解析器喂变异;回滚接口有没有版本下限 | MITM/恶意镜像→任意代码执行(全量用户);或差分解析堆破坏 | 全程 https+pinning+装前验签;更新器只下载让系统 msiexec 装(签名在 OS 层二次校验) |
| MSI/NSIS 安装包:CustomAction 跑脚本;安装目录/数据目录 ACL 松 | 7z/ORCA 解包看 CustomAction 与 `[PROPERTY]` 拼接;装完后 `icacls` 查目录(用户可写的 `Program Files` 子目录=先装后提权);app 启动链的 DLL 是否走当前目录/用户可写路径(`LoadLibrary` 搜索序劫持;利用姿势同 `../平台/01-Windows安全/病毒木马篇.md` §2.1) | 低权用户写文件→服务/开机自启高权执行时加载(提权,单机) | 有签名自检;目录 ACL 正确;DLL 全绝对路径加载 |
| 桌面 app 起本地 IPC:127 TCP 端口/命名管道/local socket 当 RPC,无鉴权 | `lsof -i`/`netstat` 列 127 面;直接裸发命令(读文件/exec);浏览器侧拉起:localhost CORS 松配置、DNS rebinding、`file://` 页 fetch | 任意网页或本地低权进程→IPC 高权命令(文件读写/exec);远程网页触发优先级最高 | 带 token/origin 校验;命名管道校验对端进程 SID;只绑 127 且 rebinding 防护开 |
| 浏览器扩展:manifest 权限宽(`<all_urls>`、nativeMessaging、cookies、tabs) | manifest 权限审计;content script 收网页可控输入(URL 参数/innerText)在扩展上下文执行;`background` 消息 handler 参数进动态执行面;nativeMessaging host 侧命令拼接 | 网页可控输入→扩展高权动作(读任意站 cookie/驱动 native host 命令注入),影响所有装该扩展用户 | handler 白名单;MV3 无动态执行面;native host 参数全枚举 |
| IDE/创作软件插件生态(VSCode/Adobe/IDE 之外的专有插件格式):插件包可侧载 | 插件包结构(zip/专有)与安装链路是否校验签名/来源;插件目录 ACL(用户可写→高权 host 进程加载 DLL 提权,同安装包行);专有滤镜/字体/模型解析器抽出来 AFL | 恶意插件包静默安装(供应链事件),或解析器内存破坏(可拿号) | 侧载被禁只认官方源+签名;解析走独立沙箱进程;插件目录权限锁死 |
| Office/文档解析面:邮件客户端/网盘客户端/预览器自带文档解析(非走系统) | 核对自带解析库版本(常是 fork 停更);对 docx/xlsx/rtf/ole 复合文档/冷门格式喂变异;RTF/OLE 历史洞模式(对象拼接/字段覆盖)在自带解析器上重放 | 打开/预览即内存破坏(默认路径触发,不用用户确认弹窗) | 解析实际委托系统组件(跟系统走已修);预览前强制转中间格式再解析;只在「另存为」死分支可达 |
| 字体光栅化:桌面/设计/游戏软件自带 freetype/harfbuzz 或自研光栅器 | 提自带库版本对照上游已修清单;GSUB/GPOS/CFF/variable font 表喂变异;触发路径:挂图字体/文档嵌入字体/网页 webfont 落缓存 | 渲染恶意字体即堆溢出(社交工程门槛低:一张图) | 用系统字体引擎(洞归系统);表长度预检全拦;字体先过子集化清洗 |
| 多媒体解码:桌面 app 静态编 ffmpeg/自研编解码器,版本停在旧 fork | `strings` 提 `Lavc`/版本号对照上游安全修复;容器(mkv/mp4/avi/wav)与冷编解码器喂变异;demuxer 长度字段信任点定位 | 打开媒体文件/生成缩略图即 UAF/溢出(缩略图=零交互) | 实际用系统 MediaFoundation;解码丢外部进程隔离;只收自家录制格式(输入域可信) |
| Qt/GTK 图片插件:app 打包自带 imageformats/gdk-pixbuf loaders | 列 loaders 目录找冷门插件(tga/pcx/ico/psd);`QImageReader` 写 harness 脱离 GUI 直接 AFL;插件版本差比对 | 缩略图/预览路径溢出(收图即崩,文件管理器式默认触发) | 缩略图走系统服务;loader 只认注册 magic 且限尺寸上限;超大尺寸预检拒收 |
| 游戏引擎资产解析:Unity AssetBundle、Unreal pak/uasset、Godot resource(带 mod 生态) | mod/官方包格式逆向;bundle 头与偏移表(长度字段直接信任)fuzz;反序列化器专打类型混淆(Unity 序列化对象类型字段、Unreal 软对象路径注入) | 加载恶意 mod/地图即代码执行(反序列化到任意类型)或堆破坏 | mod 带签名/沙箱;反序列化类型白名单;资产只在编辑器手工导入(触发门槛高) |
| 反作弊/外挂驱动:带签名内核驱动常驻暴露 `\Device\` | 同 Windows 驱动打法全套移植:设备 DACL+IOCTL 码提取,骨架见 `../平台/01-Windows安全/win-vuln/驱动IOCTL审计.md` §4;专打指针直传与物理内存映射原语(外挂驱动常自带任意读写);开发面参照 `../平台/01-Windows安全/编程篇.md` §5 | 普通用户进程→内核任意读写(该类驱动历史上批量出洞,一个洞常挂全家游戏) | 设备 ACL 限 SYSTEM;IOCTL 全缓冲且长度校验;只回数据不收指针 |
| VR 运行时(SteamVR/OpenXR/Oculus 服务):常驻系统服务+驱动+本地 websocket/jsonrpc | 服务进程权限;驱动 DLL 搜索路径;本地 websocket 面(origin/token 校验);相册/模型/手柄配置文件解析器 | 网页→本地服务命令;或加载恶意 VR 资产 RCE | websocket 带 token;资产解析在渲染进程沙箱;服务以普通权限跑(无提权收益) |
| 跨平台框架版本差:Tauri(wry)/Electron(Chromium)/Flutter(引擎) | 提框架版本对照上游安全公告(Chromium/WebKit 版本映射);Tauri `allowlist` 危险 API 暴露(fs/shell 全开);`asset:` protocol 范围穿越;IPC command 参数直接进 `Command::new` | 前端 XSS→框架桥 RCE;或带入上游已修洞(版本差举证) | 版本新无差;桥只暴露无副作用命令;asset protocol 锁死前端目录 |
| 凭证存储设计缺陷:客户端存密码用硬编码密钥加密/DPAPI 之上无 app 层隔离 | 解包客户端找加密例程:硬编码密钥(全用户同钥=一键解密所有用户凭证)/密钥存注册表同目录;keychain ACL 跨 app group 共享面;「记住密码」文件落盘内容核对 | app 层硬编码密钥加密凭证(任何人可解)=设计缺陷可报;本地凭证文件全明文(密码学失效) | 系统机制本身(DPAPI CurrentUser 可解是设计意图,单独这个不算洞);需先本机任意代码执行为前提的多数被降级/不给号 |
| npm/pypi 原生扩展:包带 node-gyp/C 扩展,解析文件/协议输入 | 剥出 native 部分→脱离 JS 写 harness 直接 AFL(见 `../平台/06-二进制漏洞/`);JS 侧只标入口与调用约定(参数可达性) | 原生层堆溢出/UAF(供应链影响=全依赖方;GHSA+CVE 双轨) | 纯 JS 逻辑洞(走 GHSA 为主);解析输入全来自包内固定文件(无不可信输入面);洞只在 devDependency 场景触发 |
| CI 脚本命令注入:仓库 workflow/build 脚本拼 shell | 输入源排查:branch 名/PR 标题/issue 内容/提交作者名→`shell=True`/`os.system`/反引号拼接;workflow `${{ }}` 展开直接进 `run:` 块(默认 shell 注入面) | 外部可控字符串→CI 环境命令执行(窃取 secrets/push 权限)。边界:多数被当供应链事件处理,CNA 常不发 CVE——报告里写清定性 | 输入只来自维护者本人操作;runner 无 secrets 可偷且无外推权限;fork PR 默认不跑该 workflow |
| 镜像与包源投毒边界:typosquat/依赖混淆/恶意包事件 | 先定性再动手:恶意包(投毒事件→平台举报+安全通告,不是 CVE)/包管理器客户端自身缺陷(元数据解析洞、scheme 混淆、降级 http、签名校验绕过→这才是 CVE 面) | 只有客户端/源服务自身可利用缺陷算 CVE;投毒包走下架+通告,价值在响应链不在编号 | 把单纯恶意包硬报 CVE(被拒);自建测试包误报(先查上传者与下载量) |
| 桌面 app 解析面 harness 化:解析函数内嵌主 EXE/DLL,想 fuzz | 先定位解析单元(IDA 导入表/错误字符串反查);DLL 有导出→直接补桩调用;EXE 耦合 GUI 消息循环→抽函数重链接或进程级喂文件+WinAFL 覆盖引导(见 `../平台/01-Windows安全/win-vuln/工具链搭建.md` §3) | PageHeap/ASAN 下稳定溢出且偏移/内容可控 | 解析静默 return 不崩;必须走完整 GUI 交互才到解析(harness 成本超收益,换入口) |
| 桌面 app 的 deep link/URL scheme 参数拼 shell:注册表自定义 scheme | 注册表 `HKCR\<scheme>\shell\open\command` 查收参方式;`%1` 引号逃逸(`"`/空格截断)→`ShellExecute`/`subprocess(shell=True)`;参数路径直接进文件写 | 网页拉起 scheme 即命令注入/任意文件写(零用户交互之外确认) | 参数只做白名单路由跳转;spawn 用参数数组不经 shell;scheme 收参后先过严格校验再分发 |
| IoT 硬件降级面(串口/调试口一行):设备留 UART/JTAG/SWD debug shell | 拆机找串口/调试点(接口识别与接线见 `../平台/07-智能设备/无线硬件/硬件接口.md` §1 四大调试接口总表、§2 UART);115200 直连进 shell;固件侧核对 telnetd/硬编码账号是否同平台复用(先 `../平台/07-智能设备/iot/固件提取.md` 拆固件) | 物理接触 root 多数不给号(标清);**同后门凭证/同 debug shell 被网络面(远程管理/UPnP)复用**才算高危升级 | 串口要拆壳+焊接;bootloader 锁写;单独「能进 shell」报 CVE 常被拒(需物理+无提权收益) |
| 生态收尾判定:桌面/生态洞要拿号,先过三问 | 受影响人群可量化(装机量/下载量/依赖树反查)+默认配置可达(不要求用户开开关)+可利用证明(不是纯理论 DoS),三缺一先补再报;参照 `../从逆向到CVE-能力审计.md` §3 共性断点 | 报告首轮过(影响面数字+默认触发两章立住) | 「用户可以自己改安全」当前提;影响面只写「所有用户」无数字 |
