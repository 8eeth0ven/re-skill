# Firmware evidence notes

Firmware triage records observations tied to an image and its files. A component string can guide a patch review, but its presence alone does not show that the component runs or is affected.

![Image provenance, a static observation and the question still open.](../assets/readme-light/firmware.svg)

Keep the image identifier, file location and observation together. If provenance or runtime status is missing, leave the conclusion open. See the [project’s evidence overview](../README.md).
