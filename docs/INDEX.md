# Documentation Routes

Use this index for setup, workflow contracts, knowledge maintenance, or historical
project records. Analysis tasks follow their direct route in [SKILL.md](../SKILL.md).
This is an optional documentation router, not a second domain taxonomy or a required
preload. Existing platform, technique, and corpus indexes own their article lists.
