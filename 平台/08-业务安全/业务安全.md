## 2. 账号安全

### 2.1 攻击面清单

- **撞库(credential stuffing)**:社工库料+代理池+自动化登录;判别面=登录无频控/无设备指纹/错误提示不分用户存在性。
- **批量注册(养号)**:接码平台(卡商/猫池/虚商号段)+ 打码平台(AI 打码已替代人工)绕过验证码,产出羊毛号;接码平台 API 化(按条计费)是黑产基础设施。
- **账户枚举**:登录/找回接口对「用户不存在/密码错误」响应差异、注册接口回显占用,可拖库前先摸清有效账号面。
- **短信/电话轰炸**:接口无频控或 uid 参数可替换轰炸他人;SRC 高发低危,量级主张须过 `闸门矩阵方法论.md` 定量收口(本机规则)。
- **账号接管组合**:改绑手机/邮箱不验证旧凭证、注销后账号重注册接管 → 归 `h1-高危害专项-认证绕过与ATO.md`。

### 2.2 防御设计(攻防对照,审计/蓝队双向可用)

| 攻击 | 防御 | 常见防御破绽 |
|------|------|-------------|
| 撞库 | 登录频控(账号+IP+设备三维)+ 滑块升级 | 只按 IP 限频(代理池即破) |
| 批量注册 | 注册行为分+设备指纹+接码号段识别 | 号段库更新滞后 |
| 枚举 | 统一错误文案、注册接口限频+模糊提示 | 找回接口漏改 |
| 轰炸 | 同号发送间隔+同 IP/设备日上限+图形验证前置 | 只限 uid 不限手机号参数 |
| 接管 | 改绑验旧凭证+敏感操作二次认证 | 改绑与解绑接口策略不一致 |

## 3. 支付安全

### 3.1 缺陷模式表

| # | 模式 | 变体 | 判真要点 |
|---|------|------|---------|
| 1 | 金额客户端可控 | price/amount/discount 直传、负数金额充值、0 元购 | 改包后订单实际成交价变化即真 |
| 2 | 数量精度 | 负数量、小数库存、整数溢出、超大数精度丢失(后端语言差异) | 订单总额与预期差 |
| 3 | 支付回调伪造 | 验签缺失/弱签名(md5 拼接)、金额不绑定订单、异步通知重放 | 本地起伪造回调能否置为已支付 |
| 4 | 优惠滥用 | 优惠券并发达上限、满减叠加计算错、邀请返利自刷闭环 | 重复请求 N 次的到账总量 |
| 5 | 竞态资损 | 余额并发消费、提现并发、秒杀超卖 | 并发包双花;细节 → `race-condition-test.md` |
| 6 | 退款滥用 | 原路退款+改绑收款账户、退款金额不校验原单、重复退款 | 退款链路身份一致性 |
| 7 | 跳单 | 未支付直接调发货/取货接口(状态机乱序) | 订单状态回放 |

### 3.2 审计/测试切入点

- 流量侧:全支付流挂 Burp,标出所有进「金额/数量/优惠/状态」的参数,逐个篡改矩阵(负/零/小数/超大/字符串)。
- 白盒侧:搜支付网关调用点,验证签名算法与验签侧是否对称、金额来源是服务端订单还是请求参数。
- 资金闭环视角(风控):充值→消费→提现的完整环路里,任何一环的凭空增额都是高危;报告定级按「可造成实际资损的路径」写。

## 4. 验证码与凭证体系

- 验证码类型:图形(打码破解)、短信(接码/轰炸)、滑动行为(轨迹模拟)、语义(弱)。
- 缺陷模式:验证码返回包回显(code 在 response)、一次验证多处复用、验证在客户端、删除验证码参数跳过校验(after 空值/0)、时间戳可预测(短信 token)。
- Token/密钥体系:JWT 弱密钥/none 算法 → `oauth-jwt-test.md`;加密接口中转(App 接口签名破除)→ `cn-business-security.md 加密接口中转`。

## 5. 数据安全(合规/脱敏)

### 5.1 数据分类分级(审计前先定级)

| 级别 | 例 | 泄露后果 |
|------|----|---------|
| 核心业务数据 | 交易流水、定价策略 | 资损/竞争优势 |
| 个人敏感信息 | 身份证/银行卡/生物特征/行踪 | 个保法重罚+刑事责任 |
| 个人信息 | 手机号/邮箱/地址 | 合规处罚 |
| 业务配置 | 内部接口/密钥/拓扑 | 攻击跳板 |

### 5.2 法规基线(国内)

《网络安全法》《数据安全法》《个人信息保护法》+ 等保 2.0;国外 GDPR/CCPA。核心义务:最小必要收集、告知同意、分类分级、出境评估(数据出境安全评估办法);违规即「情节严重」入刑(侵犯公民个人信息罪)。

### 5.3 脱敏与加密技术

- **脱敏**:静态(SDM 屏蔽生产数据入测试库)、动态(查询时遮蔽 `138****5678`)、格式保留加密 FPE、tokenization(PCI-DSS 标准,卡号换 token)。
- **存储**:密码必须慢哈希(bcrypt/scrypt/argon2,禁 md5+盐固定)、字段级加密(AES-GCM)、密钥与数据分离(KMS)。
- **传输**:全站 TLS+HSTS;内部服务间 mTLS。

### 5.4 SRC 常见数据洞

- 接口未脱敏返回身份证/手机号全量明文(配合越权=批量拖个人信息,高危且涉法)→ `idor-test.md` 对象图批量打法。
- 日志打印敏感字段、导出接口无权限、GraphQL 深查询批量拉取(→ `graphql-test.md`)、搜索联想回显他人数据。
- 密钥面:硬编码 AK/SK(白盒 grep)、配置入 git(→ `insecure-scm-test.md`)、对象存储公开桶。
- 报告涉个人信息须引合规条款定级 → `~/.zcode/rules/vuln-report-format.md`(本机规则)。

## 6. 风控对抗(互链 手法库)

```
风控信号层: 设备指纹(硬件/传感器/系统参数哈希) + 行为(轨迹/输入节奏) + 环境(代理/模拟器/Root)
     ▲对抗                                                        │
黑产工具: 改机工具(一键新机/参数随机化)、群控、云手机、              ▼
          指纹浏览器(多开隔离)、接码/打码、IP池(住宅代理)     风控决策: 名单/规则/模型分/挑战(滑块/短信)
```

- **设备指纹**:App 侧采集(Android ID/IMEI/传感器/系统属性)与对抗(伪造、隐藏、一致性检测)→ 深挖正本 `~/.zcode/skills/re/手法/04-对抗攻防/设备指纹与风控.md`;检测原理全景 → 同目录 `检测原理全景.md`。
- **行为对抗**:请求速度/频率特征是黑产最易暴露面;群控抹平个体差异仍留聚合特征(同设备簇)。
- **挑战升级路径**:规则→模型→挑战(无感→滑块→短信)的漏斗设计;黑产侧用真机农场对抗无感。
- 检测方与被检测方视角合一才完整:渗透侧过风控(注册/登录/营销接口)时先读 手法库 对抗篇,避免只从 Web 层看。

## 7. SRC 与众测体系

### 7.1 平台形态

- 企业自建 SRC(TSRC/ASRC/BSRC 类)、公益 SRC(CNVD/CNNVD 依托)、商业众测平台(补天/漏洞盒子类)、国际赏金(HackerOne/Bugcrowd)。
- 流程:注册→挖(授权范围内)→报告→审核定级→修复→评分/排名→奖励(现金/积分/致谢);重复报告合并规则。
- 白帽边界:授权书与测试范围是生命线(未授权测试即违法,刑法 285/286);数据不落地、不留存、打完即清;披露时限遵守平台协议。

### 7.2 定级思维(业务漏洞怎么写高)

| 要素 | 说明 |
|------|------|
| 危害本体 | 资损金额级?数据敏感级?接管范围? |
| 可利用性 | 是否需要前置条件(号/交互/内部参数) |
| 影响面 | 单用户/全量/特定高价值人群 |
| 组合升链 | 单洞中危 → 拼 ATO/RCE/批量拖库 → 高危(`h1-组合攻击链短表.md`) |
| 定量收口 | 「可批量/无限」类量级主张必须给数量硬下限(本机闸门矩阵规则) |

正式格式 → `~/.zcode/rules/vuln-report-format.md`。国内业务语境漏洞分布与案例 → `cn-business-security.md` 全篇(乌云 1269 篇提炼)。

## 8. 黑灰产对抗产业链图谱

```
上游(基础设施)          中游(实施)                下游(变现)
┌─────────────┐      ┌──────────────┐      ┌──────────────┐
│ 料:社工库/账号  │      │ 薅羊毛/返利自刷  │      │ 洗钱:跑分平台   │
│ 接码平台(卡商)  │ ──▶ │ 撞库盗号/诈骗引流 │ ──▶ │ USDT/虚拟卡   │
│ 打码/代理IP池   │      │ 赌博/色导/诈骗站 │      │ 电商套现/销赃   │
│ 工具:改机/群控/ │      │ 网络水军/舆情   │      │ 广告作弊(点击) │
│ 云手机/指纹浏览器│      │ DDoS勒索/CC    │      │ 数据倒卖       │
└─────────────┘      └──────────────┘      └──────────────┘
        对抗:号码实名/一证多号治理、支付断直连、App备案、AI风控、专项打击
```

- **治理侧手段**:断卡行动(卡商)、号码实名+入网核身、支付限额与断直连(资金)、云厂商内容安全(赌博站)、专项打击(公安部净网)。
- **攻防研究价值**:识别产业链分工即可在 SRC 中预判「这个洞黑产会不会用」→ 直接决定报告危害定级(如批量注册面=养号基础设施=高危)。
- **羊毛党/真人作弊**区别于机器作弊:真人众包(接任务平台)最难用设备指纹防,靠资金闭环与行为聚簇检测。
