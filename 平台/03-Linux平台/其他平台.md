## §1 概述 [1001014]

"其他平台"是知识库对主战场(Windows/Android/iOS/Linux)之外所有平台的收纳箱,时间跨度 30 年。方法论一句话:**换平台 = 换文件格式 + 换指令集 + 换系统调用面,逆向方法论(静态结构→动态行为→定位关键路径)不变**。

## §3 容器安全 [1001721]

树中最年轻节点。容器本质是**共享内核的隔离进程**——所以容器安全 = 内核隔离机制(namespaces/cgroups/capabilities/seccomp) + 守护进程面(Docker daemon/containerd/K8s 控制面)。

```
逃逸路径总览:
容器内进程 ──┬─ ① daemon API 未授权(2375 裸奔)──挂载宿主根 → 直接拿下
             ├─ ② privileged 特权模式 ── mknod 磁盘/加载内核模块 → 逃逸
             ├─ ③ 挂载敏感路径(/var/run/docker.sock、/proc、/)
             ├─ ④ 内核漏洞(dirty cow / dirty pipe / CVE-2020-15257 shim 抽象套接字)
             └─ ⑤ K8s 面组件(kubelet 10250、dashboard、etcd、RBAC 失配)
```
(自绘 ASCII)

### 3.1 检测与手法清单

- 容器自检(样本/蓝军视角):`/proc/1/cgroup`(含 docker/kubepods)与 `/.dockerenv` 存在、`capsh --print` 能力集、`fdisk -l` 能看到宿主盘 = 特权容器。代表帖:app 检测自身是否运行在 docker 容器中。
- 逃逸五型与案例帖:
  1. daemon 未授权:docker-remoter-api 渗透
  2. privileged:docker 利用特权模式逃逸拿主机
  3. CVE-2020-15257(host 模式下 containerd-shim 的 abstract unix socket 可直连):CVE-2020-15257 host 模式逃逸分析
  4. Docker Engine 授权插件绕过 CVE-2026-34040:Docker Engine CVE-2026-34040 容器逃逸
  5. K8s 集群攻击面:K8S 集群安全(攻击者视角·上)
- seccomp 与 ptrace 优先级(ptrace 被默认 seccomp 挡住的场景):ptrace 绕过 seccomp(星门题解)

### 3.2 逆向视角

恶意样本进容器后行为与 Linux 用户态完全一致(ELF 生态,见《Linux安全.md》);容器侧新增的是**样本的环境感知检测**(§3.1 自检)与**云原生持久化**(daemon 挂马、恶意镜像层、sidecar 注入)。分析环境本身也容器化——沙箱即镜像,好处是 strace/gdb 全家桶随 Dockerfile 秒级重建。

## §4 PSP 游戏机平台 [1001015]

- **架构**:Sony 自研 Allegrex(MIPS32 核心 + VFPU 向量协处理器,主频 333MHz)。逆向 = MIPS 反汇编 + VFPU 特殊指令集。
- **文件**:`EBOOT.BIN`(主程序,加密后为加密 ELFMIPS 变体)、`BOOT.BIN`(明文)、`PRX`(可重定位模块,相当于动态库);固件本身也是 PRX 集合。
- **破解史主线**(早期热门):①固件 dump(通过漏洞读 flash)→ ②解密 PRX(早期用 "decryption prism" key 泄漏事件)→ ③自制固件 CFW(custom firmware,改 loader PRX)→ ④ Pandora 电池(神奇电池,改 serial 进入 service 模式刷机)。
- **现代玩法**:模拟器(PPSSPP)内动态调试比真机方便得多;UMD iso 直接挂载读文件系统。
- 历史帖集中在 2005-2010,语料检索「PSP」可得破解帖。

## §5 6502 与复古计算 [1001016]

- 6502:8 位 CPU(Apple II、Commodore 64、FC 红白机 CPU 2A03 即 6502 改),无乘除指令、零页寻址(0x00-0xFF 当寄存器用)、栈固定 0x0100 页。
- 逆向对象是**裸 ROM/PRG**(无文件格式、无重定位):ID A(`ida -m6502`)、radare2、专用反汇编器;FC 侧配 mapper(iNES 格式 .nes)知识。
- 知识库收录多为早期红白机/苹果机破解与反汇编教学帖(树节点早期内容)。

## §6 DOS 系统 [1001017]

- **格式**:`.COM`(纯二进制映像,加载到 0x100,无头)/ `MZ EXE`(带重定位表的 16 位可执行,PE 的直系祖先)。
- **运行面**:`int 21h`(DOS 服务)、`int 10h`(BIOS 视频)、TSR 常驻、`PSP`(程序段前缀 ≈ 命令行+环境块)。实模式无保护,程序可直接摸全部 1MB——病毒黄金时代。
- **病毒技术**:引导区病毒(MBR/DBR 寄生)、文件型(COM/MZ 附加或空洞注入)、多态加密引擎(经典教材即知识库收录的 Billy Belceb 病毒教程 DOS 篇 [1000931],位于 Windows安全/病毒技术区)。
- **现代分析**:DOSBox + debug.exe(MS-DOS 自带调试器,16 位实模式调透彻);IDA 支持 16 位 x86 与 MZ。
- 知识库树中 DOS 节点保留的是 PC 安全史前史;《读书笔记DOS下可执行文件的加载》、《关于在DOS下如何调用汉字库显示汉字》、《grub for dos bootloader 分析》、《grub for dos 引导部分 stage1分析》。

## §7 Symbian 平台 [1001018]

- 塞班系统:诺基亚主导,ARM9/11。**E32 image** 格式(魔数 `EPOC`)自带压缩与 UID1/2/3 校验;安装包 SIS/SISX(签名制)。
- 逆向链:SIS 解包 → E32 image dump(内存中已解压)→ IDA ARM 分析。S60 平台 Python/C++ 混合,库符号(semc/nokia)较全。
- 安全面:Symbian Signed 绕过、能力(capability)模型、证书破解(DRM 破解史)。社区活跃期 2005-2012,是 Android 时代之前手机逆向主战场。
- 代表帖:《Symbian 60手机软件破解手记》、《Symbian virus 分析 Part I》、《Understanding Symbian virus (II)》、《Symbian函数或类与头文件和LIB库对照表》、《新的Symbian OS 9 可执行文件格式(E32Image)》——E32 格式/病毒分析/破解三面齐备。

## §8 Windows CE / Windows Mobile [1001021]

### 8.1 系统结构 [1001022]

WinCE 与桌面 Windows 同源不同核:模块化内核(nk.exe)、对象存储(Object Store)、4GB 虚存统一布局(每进程 32MB slot);进程/线程 API 形似 Win32(kernel32 子集),系统调用经 `TrapAPI`/直接 swi。

### 8.2 逆向 [1001023]

- 文件:PE 变体(ARM/MIPS/SH4/x86 交叉编译,`IMAGE_FILE_MACHINE_ARM` 等)+ `.cab` 安装包(可 `extract`/msi 反解)。
- 工具:IDA(ARM 支持主力)、WinCE 自带 Remote Tools(PRV 等)、模拟器(Visual Studio Emulator / Device Emulator)——**模拟器快照调试**是当年最舒服的路径;真机侧 ActiveSync + 远程调试代理。
- 破解对象:导航软件(当年国内最大宗)、输入法、共享软件注册。手法与 Win32 同源:找注册校验、patch、重签。

### 8.3 安全 [1001024]

签名许可特权层(trusted tier)、系统证书伪造、内核 nk patch;以及后来 WP 时代彻底转封闭。代表帖:《Windows CE 必备开发工具总结》、《一种Windows CE 平台AutoRun程序的实现方法》、《IDA远程调试WINCE程序的环境搭建》。

### 8.4 程序开发 [1001025]

eMbedded Visual C++ / VS2008 Smart Device;驱动与系统能力开发经验帖归此节。逆向者的开发知识主要用于写补丁 DLL 与 RAPI 工具。

## §9 BlackBerry OS [1001026]

- 格式 **COD**(Java 字节码压缩变体,J2ME 血统):ALX/Sibling/JAD 安装描述 + COD 主体。
- 逆向链:COD → 解包(`cod-decoder` 类工具/zip 解压变体)→ class 字节码 → dex2jar/JD-GUI 等 Java 工具直接复用。
- 破解对象:BES 企业邮件策略、第三方 Java 应用注册码。活跃期 2008-2013;代表帖:《BlackBerry 9530 CDMA MEID/ESN保护》、《反编译黑莓手机COD格式文件》。

## §10 Windows 3.x [1001289]

- 格式 **NE**(New Executable,16 位):MZ 头 + NE 头,段表无虚拟地址概念(加载时分配)、`res` 资源表、entry table。PE 的直接前身——看 PE 演化史的活化石。
- 16 位破解:seg:offset 地址换算、thunk(16/32 混合)、局部堆/全局堆;工具 SoftICE(16 位时代王者)、TD(Turbo Debugger)、现代 IDA。
- 早期大量 NE 破解教学帖沉淀于此。
