分层要点:
- **固件层**:内核裁剪错误、旧版 busybox/lighttpd/goahead、硬编码凭据——绝大多数 RCE 的出生地(见固件提取/路由器实战)。
- **Web 接口层**:goahead/lighttpd + cgi(`htdocs/web/*.cgi`)是最常见的组合,命令注入高发区(路由器实战 §1)。
- **云 API 层**:设备身份(序列号/MAC)即凭证、token 可预测、OTA 包签名缺失;社区相关帖集中在 App 逆向(归 02-Android安全)加云接口联测。
- **近场无线层**:BLE 配网广播密钥、Zigbee 无重放保护(归无线硬件/BLE与Zigbee)。
- **物理层**:调试口、Flash(归无线硬件/硬件接口)。

## 2. 标准工作流(社区 IoT 帖的共同骨架)

1. **拿固件**(官网下载 / OTA 抓包 / SPI 摘读 / uboot console / 后门账号——固件提取)
2. **解密**(若有加密头——固件解密)
3. **解包**(`binwalk -Me`——固件提取 §3)
4. **文件系统里翻证据**:硬编码凭据、`/etc/passwd`、启动脚本 rcS、cgi 目录、`strings | grep -i pass`
5. **仿真或真机**(固件仿真)
6. **从 Web/cgi/私有协议入口打漏洞**(路由器实战/协议与服务)

代表帖:
- 智能硬件入门(USBPcap/Wireshark 工具链与固件升级机制,入门首选)
- 智能家居安全思维导图(攻击面分类图,内容已并入 §1)
- IoT设备固件分析教程之固件是怎么存储的(Flash 分区布局底座)
- IOT基础设备及固件提取分析
- 汇总入口:智能硬件版块精华汇总

## 4. 学习路线(本组收束)

1. 入门:智能硬件入门帖 → 版块汇总帖 → DIR-815 帖(栈溢出)→ CVE-2018-17066(命令注入)
2. 进阶:FirmAE 仿真帖 → D-Link 解密帖 → Qiling 帖 → boofuzz 帖
3. 深水区:VxWorks 符号恢复 → 工控 PLC 蠕虫 → MQTT/CoAP 实现 bug
4. 所有路由器 CVE 帖共用一个元方法:**固件拿到 → 仿真 → cgi 里找 system/xref → 包验证**;换厂商只是换结构不换方法。
