# 汽车安全:CAN/UDS/钥匙


## 1. CAN 总线

```
节点(ECU) ──┐
节点(网关) ──┼── CAN_H/CAN_L(差分,120Ω 双端)── 广播无地址
节点(仪表) ──┘   仲裁:ID 小优先级高;无认证无加密
帧: [SOF|ID(11/29)|RTR|DLC|DATA(0-8B)|CRC|ACK|EOF]
```

- CAN协议分析(报文结构与实验方法)
- 汽车CAN协议hacking(国内早期开山帖)
- 实操:OBD-II 口 + CANable/Kvaser + SavvyCAN/candump;`cansend can0 123#DEADBEEF` 逐 ID 摸语义(车窗/转向/解锁),重放报文是最快验证。
- UDS(ISO 14229 诊断协议):0x10 会话/0x27 安全访问/0x2E 写 DID/0x31 例程——使用STM32开发板实战汽车UDS诊断;27 服务的 seed-key 算法逆向=ECU 固件逆向(回 [../iot/固件提取.md](../iot/固件提取.md))。
- ECU 固件:汽车动力系统ECU固件逆向工程初探、汽车ECU升级初探、汽车诊断工具的实现
- 车机互链:车机 Android 系统的逆向(APK/so/系统服务)完整工具链互链 手法库(同 skill re/手法)(`01-方法论/` 与 `02-frida/`);车机固件提取帖见 [../iot/固件提取.md](../iot/固件提取.md) §3。
