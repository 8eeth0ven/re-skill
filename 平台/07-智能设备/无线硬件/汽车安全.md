## 1. CAN 总线

```
节点(ECU) ──┐
节点(网关) ──┼── CAN_H/CAN_L(差分,120Ω 双端)── 广播无地址
节点(仪表) ──┘   仲裁:ID 小优先级高;无认证无加密
帧: [SOF|ID(11/29)|RTR|DLC|DATA(0-8B)|CRC|ACK|EOF]
```

## 实战案例补充

### 零成本入门车联网安全研究
作者:kxliping

无实车搭接近真实域架构的仿真环境(一台机器即可):

- 架构:VCU 整车控制域(BDCAN 车身 + ASCAN 自动驾驶,cangw 网关互联) + HU 信息娱乐域(ICCAN 仪表 + CAMCAN 摄像头),域间用以太网互联;两路以太网连接按安全等级用 VLAN 隔离(ADAS 报文与普通控制报文分广播域)。
- 车辆功能用 ICSim 模拟:`./icsim vcanic` 绑仪表、`./controls vcanbd` 模拟车身零部件发 CAN 报文;vcan 创建:
```
sudo ip link add name vcanic type vcan && sudo ip link set dev vcanic up   # vcanbd 同理
```
- CAN-ETH 跨域打通用 cannelloni(SocketCAN over UDP,单机用不同端口区分域):
```
cannelloni -I vcanbd -R 192.168.20.100 -r 20001 -l 20000
cannelloni -I vcanic -R 192.168.20.100 -r 20000 -l 20001 -p
```
- VLAN:`sudo vconfig add enp0s31f6 20/30` 建 vlan id 子网卡,分网段配 IP 后互 ping 100% 丢包即隔离成功。
- 防火墙做最小权限(HU 只收车身报文、只发摄像头报文):iptables 按 UDP sport/dport 精确 ACCEPT + 兜底 DROP。
- 域内网关:`sudo cangw -A -s vcanbd -d vcanas -e`(双向各一条);cangw+cannelloni 组合已接近真实 CAN 网关(真网关还带 LIN/FlexRay)。

### 汽车智能警报器的安全问题分析
作者:0xbird(翻译)

后市场智能警报器(Viper/Clifford、Pandora)云端 API 的 IDOR 打法:

- 链路:未授权篡改 API 参数改任意账号注册邮箱 → 密码重置发到攻击者邮箱 → 接管账号 → 定位跟踪/解锁车门/启停防盗/行驶中熄火/远程开麦克风监听(SOS 麦克风)。影响约 300 万辆车。
- Viper(后端 colt.calamp-ts.com):其余 API 均校验授权,唯独 `POST /users/Update/{uid}` 漏验 → 直接改任意用户 Email+Password 字段接管。
- Pandora(pro.p-on.ru):`POST /api/sputnik/workers?id={uid}` 改 JSON body 的 email 字段覆盖原邮箱;顺序用户 ID 可遍历,打到管理员账号可看其名下全部车辆。
- 入口技巧:两家都开放免费注册测试/模拟账号,不买产品即可持合法会话访问真实账户数据(打 IDOR 的最低成本入口)。
- 深挖思路:UI 没有 ≠ API 没有:App 界面无"熄火"按钮但 API 存在该功能;警报器为省布线直连 CAN 并可发自定义 CAN 报文,自动识别车型失败时靠安装器本地编程(笔记本工具/蓝牙 App)——分析固件+手册+changelog 可发现隐藏的无线编程 API。
- 危害面:受影响车型(马自达6/揽胜运动/RAV4 等)可远程改巡航速度、伪造制动踏板报文;警报器无一额外中继防护,反而给无钥匙车新增攻击面。

### 汽车插线端子逆向分析
作者:星舆实验室

无手册黑盒下从 ECU 插线端子入手逆向整车网络:

- 通用第一步:在一堆针脚里先找电源针脚(VBAT/IG/地),上电后才谈找 CAN/UART/USB 调试口;端子引脚定义是黑盒物理分析的地图(实测空调控制器 A11/A12 = IBUS CAN-H/CAN-L,传感器/执行器引脚一眼可分)。
- 以网关端子为纲梳理整车拓扑,8 个子网:DiagBUS(诊断)、TBUS(远程监控,仅 T-BOX)、EVBUS(能量/动力)、FCBUS(快充)、CBUS(底盘)、IBUS(信息娱乐)、EBUS(车身)、LIN。
- 高价值端子特征:
  - T-BOX(TBUS 独占):CAN + SPK/MIC(eCall)+ 唤醒;部分车型带 USB(模拟以太网)与 UART 调试串口——远程控车的正门。
  - BMS 在快充网络中充当 EVBUS↔FCBUS 网关;PEU 电机控制器同时接 EVBUS 与 CBUS(跨域跳板)。
  - 组合仪表与车机同在 IBUS 且不经网关直接互通:拿下车机即可直达仪表。
- 快速排除非攻击面:后排 USB 只有电源针脚无数据线、点烟器仅电源——端子图一眼排除,省测试时间。
- 冷门控车链:DVR 行车记录仪接在 EBUS 车身域 CAN → 无接触漏洞拿下 DVR 系统权限 → 进入车身域 → 同网 BCM 控车门/车灯。众人注意力在云端/T-BOX/IVI,DVR 是未被广泛关注的入口(该实验室已实战拿到某车 DVR 权限)。
- 拆车/台架索引:按线束定位 ECU——T-BOX/EPB/GPS/倒车雷达挂车身线束,网关/OBD 口/BCM/PEPS/转向柱锁挂仪表线束,ADAS 前摄/天窗/雨量传感器挂顶棚线束。

### 5G时代车联网安全的未来与展望
作者:Editor(SDC 圆桌速记,观点摘录)

- 车联网四攻击方向:总线/ECU(需物理接入)、车联网链路(APP→云 TSP→T-BOX→车身,日本称 TCU)、自动驾驶传感器(视觉对抗:直线被识别成弯道)、V2X。
- V2X 硬瓶颈:车车通信验签要求约 3500 次/秒,现行安全手段达不到 → 消息层攻击是重点;一条假消息经"鱼群算法"车车扩散可致大面积交通瘫痪。
- 案例:特斯拉 Model S 钥匙用外包商过时 DST40 算法,数秒复制;T-BOX 仅 512K 存储,移动端加固方案装不下——资源受限系统防护需专门设计。
