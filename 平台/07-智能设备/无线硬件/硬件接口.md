# 硬件接口:识别、提取与芯片攻击


## 1. 四大调试接口总表

```
         ┌─────── 设备 PCB ───────┐
  UART ──► TX RX GND(3-4 焊盘成排,最常见)
  JTAG ──► TCK TMS TDI TDO RST GND(8-14 脚/测试点)
  SPI  ──► CLK MOSI MISO CS + VCC GND(挂 Flash 芯片)
  I2C  ──► SDA SCL + VCC GND(挂 EEPROM/传感器)
         └────────────────────────┘
```

| 接口 | 用途 | 识别法 | 工具 |
|------|------|--------|------|
| UART | 系统 console(打印+shell) | 万用表量 GND;TX 空闲态高电平;成排 4 孔 | USB-TTL(PL2303/CP2102/FT232)+ 杜邦线 |
| JTAG | 边界扫描/halt CPU/dump | 芯片手册+测试点丝印 | JLink/OpenOCD |
| SPI | 读挂载的 NOR/NAND Flash | Flash 芯片丝印(W25Q64/EN25Q/MX25L)查手册 | CH341A+SOIC8 夹 / flashrom |
| I2C | 读小 EEPROM(24Cxx) | 丝印 24C02 等 | 同上(CH341A 支持 I2C) |

## 2. UART 实战(路由器第一枪)

代表:路由器基本调试一 UART定位(定位方法+波特率手测)、上手学习路由器漏洞-腾达F6 关于ttl(TTL=UART 俗称)、华为光猫HG8245H救砖笔记系列(UART 救砖+完整救机流)。

步骤:
1. 拆板找焊盘(板边成排 4 点/4 孔);2. 万用表黑表笔定 GND,红表笔找空闲 3.3V 的 TX;3. USB-TTL 接 RX←TX 交叉;4. `screen /dev/tty.usbserial 115200`(常见 115200/57600/38400);5. 上电看打印,回车出 shell 或输错三次等 dropbear。

## 3. SPI/Flash 摘读

- **夹具法**:SOP8 测试夹 + 编程器(RTL8185/CH341A/NorWriter),免拆焊;车机帖完整演示从拆机到 `flashrom` 读出(见 [../iot/固件提取.md](../iot/固件提取.md) §3)。
- **带电 in-system 读**:SOIC8 夹子夹住 Flash 芯片,主机用 `flashrom -p ch341a_spi -r dump.bin`;主板供电与编程器供电冲突时需隔离(剪 VCC 或断电阻)。
- 读出后用 `binwalk -E dump.bin` 看熵分布判断有没有加密(→ [../iot/固件解密.md](../iot/固件解密.md))。

## 4. SWD:STM32/单片机 dump

ARM Cortex-M 用 SWD(两线 SWDIO+SWCLK)。ST-Link/JLink + OpenOCD,`flash read_bank 0 fw.bin`;读保护(RDP)时 Level1→Level0 回退会擦 Flash,Level2 需电压毛刺(§7)。配套逆向见 [../iot/固件提取.md](../iot/固件提取.md) §6.3。

## 5. 总线协议:RS-485/CAN/USB

- **RS-485**(半双工差分 A/B 两线,楼宇对讲/工业传感主流):逆向狄X楼宇对讲机的485控制协议(RS-485 半双工总线协议逆向,UART 帧格式+厂商私有指令集还原,嗅探→重放→指令表)。
- **CAN**:见 [汽车安全.md](汽车安全.md);**USB 协议分析**:USBPcap+Wireshark(智能硬件入门帖)。
- lora:lora固件库修改支持接收错误数据包。

## 7. 侧信道与故障注入(芯片攻击)

社区四帖一套:
- 时钟毛刺攻击绕过密码校验
- 差分功耗分析破译AES密钥(DPA:采集 N 条功耗曲线对齐后按 key 猜想分组做均值差)
- 功耗分析爆破密码
- 时钟错误注入

原理速记:毛刺=在条件判断瞬间破坏时序使跳转失效;DPA=CMOS 功耗与被处理数据汉明重量相关。设备:ChipWhisperer 开源套件为主。U-Boot 被锁时的 Glitch 退路应用见 [../iot/固件提取.md](../iot/固件提取.md) §2。
