# APK analysis records

This directory documents a workflow for reviewing Android packages. A useful report names the input, points to the file or observation behind each claim, and states which stages actually ran.

![Package identity, an evidence location and a review note.](../assets/readme-light/apk-evidence.svg)

Treat a skipped stage or a missing tool as a gap in coverage. A report based only on static files cannot confirm device behavior. [Project overview](../README.md).
