# frida 环境与快速开始

> 面向 Android 逆向的 frida 入门:安装、spawn/attach 两种启动方式、frida-server 自定义端口、frida-trace 快速追踪、Java.perform 基本结构。

## 一、安装

### 1.1 python 安装(最常用)

```bash
pip install frida
pip install frida-tools
```

### 1.2 npm 安装(TS 类型提示用)

写脚本时配合编辑器补全 frida-gum 的类型定义:

```bash
npm i @types/frida-gum
```

## 二、执行一段简单的 js 代码

先写一个最小可运行的脚本,验证环境通不通:

```javascript
// 最小脚本:验证 Java 层可用
function main(){
    Java.perform(()=>{
        console.log("成功运行")
    })
}
setImmediate(main)
```

## 三、启动方式:spawn 与 attach

### 3.1 spawn 模式(-f 从头拉起进程)

```bash
frida -U -f 包名 -l 脚本.js
```

其中 `-U` 是指定设备(USB 设备),`-f` 是以 spawn 模式启动。spawn 模式下脚本会在 app 最早阶段生效,适合 hook Application、加固壳初始化、JNI_OnLoad 等早期逻辑。

### 3.2 attach 模式(-F 挂前台应用)

```bash
frida -H 192.168.0.100:14725 -F -l 脚本.js
```

`-F` 是以 attach 模式启动,`-H` 是连接这个地址,frida-server 也需要改掉相关的端口。

### 3.3 frida-server 自定义端口

配合 `-H` 使用,设备端把 frida-server 监听到所有网卡:

```bash
frida-server -l 0.0.0.0:14725
```

基本上用的最多的运行命令就是这些。

### 3.4 不是 app 的场景(普通可执行文件)

attach 已有进程:

```bash
frida -U -p 3173 -l your_script.js
```

spawn 启动可执行文件:

```bash
frida -U -f /path/to/your/executable -l your_script.js
```

## 四、Java.perform 基本结构

所有 Java 层 hook 都必须包在 `Java.perform` 里执行(等 VM 就绪后再跑):

```javascript
Java.perform(function () {
    // 这里拿类、改 implementation
    var ExampleClass = Java.use('com.example.ExampleClass');
});
```

配合 `setImmediate(main)` 可以把入口包成函数统一调度。

要点:
- `Java.use(类名)` 拿到类包装对象;`类.方法.implementation = function(){...}` 替换实现。
- 同名重载方法用 `.overload('参数类型', ...)` 指定具体签名。
- 原逻辑调用写 `this.方法(...)`。
- 主动 new 对象用 `类.$new()`;构造函数 hook 用 `类.$init`。

## 五、frida-trace 快速追踪

不写脚本、先快速摸一个 app 的 native 行为时用 frida-trace:

```bash
frida-trace -U -f com.lucky.luckyclient -a "libc.so!"
```

- 上面这条是 hook libc.so 下面全部函数。
- 会在当前目录的 `handlers/` 目录下生成关于 libc.so 全部函数的 hook 处理脚本(自动生成 `__handlers__/libc.so/xxx.js`),可以手工编辑这些模板改打印逻辑。
- `-a "模块名!"` 指定要 trace 的模块;也可以用 `-i 函数名` 只跟单个导入函数。

## 六、常见排查

| 现象 | 处理 |
|------|------|
| `Failed to spawn: unable to find process with name` | 包名写错,或用 `-F` attach 前台 |
| attach 上去脚本不生效 | 加固/多 classLoader 场景,见 `java层/加密与自吐.md` 的「加壳的 hook」与 `03-脱壳dump/dex脱壳.md` |
| spawn 闪退 | 目标有反调试,先看 `高级/检测绕过片段.md` |
| 远程 `-H` 连不上 | frida-server 端口没改、没监听 0.0.0.0,或端口被占用 |
