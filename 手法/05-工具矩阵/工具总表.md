# Android 逆向工具总表

> 状态口径：活跃 = 近一年内有版本或代码更新；停更 = 官宣或超一年无更新；被替代 = 有更强继任者。
> 安装口径（2026-10 恢复）：每个工具给**一种最省事装法**——brew / `uv pip`（python 系，进本库 tools-env 的装法见各分篇「安装速查」）/ `npx` 一键 / 仓库简写（github.com/owner/repo）；「待核」= 仓库地址未核实；官网类给域名；「—」= 无需安装（手工/随宿主）。
> 配套细篇：《静态分析工具.md》（反编译器/ROSAL/SnikrFlow/DexKit/dexllm/加固识别）、《专项与信息收集.md》（APKiD/apkleaks/DIE/DroidLysis/androidReverse/LIEF/010 等）；**手游框架(Unity IL2CPP/UE/Cocos/RN Hermes/Flutter blutter·dae)教程级全流程在 `../14-手游框架/` 四篇**，本表 IL2CPP/Flutter 工具行与彼互链。

## 二、选型决策树（拿到 APK 怎么配工具链）

### 场景 A：看协议（接口/参数/加密）
1. 先上 **jadx** 看 Java 层：OkHttp/Retrofit 封装、加签函数名（`sign`/`token`/`encrypt`）。
2. **Reqable/mitmproxy** 挂代理；被 SSL pinning 挡 → **frida + unpinning 脚本**（或 objection `android sslpinning disable`）。
3. 代理配不上（非 HTTP/双向锁死）→ **r0capture** 直接在 socket 层收明文。
4. 参数在 native 算 → 记下 so 与导出名，转场景 D。

### 场景 B：脱壳
1. 先识别壳（so 名/特征，见《静态分析工具.md》特征表）。
2. 整体壳（一代）→ **FRIDA-DEXDump**（root+frida）或 **BlackDex**（免 root，Android ≤12 最稳）。
3. 抽取壳 → **FART + FartFixer**（主动调用补方法体）。
4. 指令级/VMP 壳 → dump 后方法体仍缺 → 只能 hook 到调用现场（frida `Interceptor` 上下文里读解密后内存），或转 native 分析（VMP 的 java 层没有完整还原价值）。

### 场景 C：改逻辑（patch/持久 hook）
1. Java 层小改 → **apktool 反编译 → smali patch → Uber Apk Signer 签名**。
2. 需要长期运行 hook → **LSPosed 模块**（Android ≤15；15 用 canary）。
3. 临时/灵活 → **frida 脚本常驻**（`frida -U -f` spawn）。
4. 无 root → **frida-gadget 重打包** 或太极系虚拟化（检测重，慎用）。

### 场景 D：过检测跑起来（root/frida/模拟器检测）
1. Root：**Magisk v30 + Zygisk + Shamiko + Zygisk-Assistant(+HMA)**；检测严 → **KernelSU + SUSUFS + ReZygisk** 内核路线。
2. frida：**strongR-frida**（或自编译 hluda）+ 改名改端口；仍被扫 → **gadget 注入**。
3. 模拟器特征重 → 换**云真机/二手真机**。
4. 过检测后回到 A/B/C 场景继续正题。

### 场景 E：算法还原（签名/风控 so）
1. **unidbg** 直接拉 so 黑盒跑（补环境见专篇《模拟执行框架.md》）。
2. 跑不通/要看清逻辑 → **IDA/Ghidra** 静态 + **frida 主动调用**对照。
3. 要产品化 → **unidbg-boot-server** 包成 HTTP 签名服务。

## 三、趋势备注（2024-2026）

- 主流免费加固（360/乐固/梆梆/爱加密）的 DEX 层脱壳已高度自动化，厂商重心转向 **Java2C + VMP + 指令级加密**，以及"御 AI 对抗式加固"（防 LLM 辅助逆向）。
- frida 生态仍是动态分析绝对中心；Xposed 系进入"维护期"（LSPosed 官宣停更后靠 canary 续命），新功能开发基本只在 frida 侧。
- Root 对抗主轴从用户态（MagiskHide→Shamiko）转向**内核态**（KernelSU/APatch + SUSUFS）。
- 抓包工具格局：Charles/Fiddler 停留在维护态，**Reqable + mitmproxy** 成为 2025 后主力组合。
- 2026 下半年「agent-first 逆向」成势：REA（通用 MCP 底座）带出 eleven/recurse/knife/r0re 一批工具，工作流从「人用工具」转向「agent 用工具、人验收」；第 8 区收录该波核心，工具雷达按月跟进。
- 2026-10 生态动向：Claude skill 生态爆发（reverse-skill/android-reverse-engineering-skill 等万星级 skill 包）；调试器 MCP 补齐（WinDbg/x64dbg/Binja/r2 官方系，见《08-AI逆向/AI逆向工具生态.md》）；「APK 即数据库」零预处理反编译（ASC）代表 Agent 时代的性能路线；reverify 开出「防幻觉验证层」新品类。
