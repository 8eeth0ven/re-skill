# Example inputs

Small text files illustrate the runner’s input contract. The [asset manifest](assets.local.json) groups example inputs, including an API description and a software bill of materials.

![The sample manifest, its input files and the explicit scope are separate.](../assets/readme-light/examples.svg)

Compare the [SBOM sample](sbom.json) with the [scope example](scope.localhost.json). These are descriptions of inputs; they do not establish that a service was contacted or a device was tested.
