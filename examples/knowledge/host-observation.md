# A Recorded Host Python Arithmetic and Encoding Observation

Evidence default: inference; only tagged claims inherit listed evidence.

## Problem and Scope

Show how an actual local execution can be recorded without labeling it physical
device verification. The host was macOS 26.6.2, Darwin 25.6.0, arm64, running
CPython 3.13.7. The [record](evidence/host-observation/record.json) was captured at
`2026-10-28T17:18:10+00:00`, which is `2026-10-29T01:18:10+08:00`.
Metadata uses the record's UTC calendar date consistently.

## Bounded Reproduction and Evidence

The small [source](evidence/host-observation/observe.py) generates its own inputs,
records runtime/host versions and the source hash, and writes UTF-8/LF JSON to
stdout. It uses only the Python standard library. To collect a **new** observation,
use the installed observer's absolute path and an existing project workspace.
Replace both example paths with actual absolute paths; on Windows use native
paths such as `Path(r"C:\Research\project")`. This binary-file capture avoids
shell-dependent redirection or encoding changes:

```python
from pathlib import Path
import subprocess
import sys

observer = Path("/absolute/re-skill/examples/knowledge/evidence/host-observation/observe.py")
project = Path("/absolute/project-workspace")
destination = project / "host-observation-new.json"
with destination.open("xb") as output:
    subprocess.run([sys.executable, "-B", str(observer)], cwd=project,
                   stdout=output, check=True)
```

Use a distinct filename; retain the historical attachment and its original date.
Compare the output with the two controls, record the actual new environment and
date, and compute the final stored-byte SHA-256 if promoting the new record.
The attached record's SHA-256 is
`252b4b4c801b3e5c8d7ca5cc1e43c646ad551835e03962ed1687ae29b982882f`.
Its source hash is recorded inside the JSON. No private target or session data was
collected; no Android shell, ADB, network or physical-device command was executed.

## Pitfalls and Related Route

A successful generated-input result cannot establish target transport integrity
or shell integer behavior. A readable attachment and matching hash establish
current access/integrity, while source authenticity and scope still require human
review. Follow the
[observation-domain gate](../../docs/knowledge-engineering.md#addendum-observation-domain-and-bounded-offline-records)
and keep current rerun state separate from this historical record.
