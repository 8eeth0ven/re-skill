## 1. PC 游戏封包加密还原
### 某游戏封包加解密算法及其算法KEY的算法
- 服务器下发钥匙包含 SendKey/RecvKey 两字段,封包前2字节为长度不加密;key 提取混淆(amwmqj):`((~((k ^ 0x6D23CF) - 0x6D2399)) & 0xffff00) | ((~((k ^ 0x2E6D23CF) - 0x2E6D2399)) >> 0x18) | ((~((k ^ 0xFFFFFFCF) + 0x67)) << 0x18)`,Send/Recv 各一套。
- **封包加密=查表 XOR 滚动密钥**:按 DWORD 分块,每步 `NextKey = Pack_Tabel[(AddNum % 0x162F)*4] + 0x2E6D23C1`,明文块 XOR NextKey;尾部不足4字节按字节 XOR 后 `NextKey >>= 8` 逐字节处理;每个密钥依赖上一个(错一个全错)。
- **定位法**:对密钥包内特征字节(如 AD)下硬件访问断点,断处直接读 key 运算汇编;汇编逆成 C++:按寄存器追踪(EDX/ECX/EBX 修改链各自抽出),用等同运算符整合(`xor edx,imm`=`sKey^=imm`,前句输出作后句输入,`or ecx,ebx`=`|` 拼接子表达式),嵌套成单表达式。
> 同法:破解金山某游戏封包加密算法(callwhl)——同款引擎,同样 Pack_Tabel 查表+0x2E6D23C1+0x162F 取模滚动 XOR;定位法为 bp send→EBX 密文缓冲区向上回溯 memcpy 源→「call ecx 执行前后缓冲区由明文变密文」即加密函数;长度写入封包尾2字节(明文),解密时须剔除。
### 武林外传登陆数据包加密算法分析
- 登录时服务器先下发随机密钥(嵌在数据包特征与偏移之间)→客户端混合运算后回发验证(认真的雪)。**加密核心=无跳转魔改 MD5**:主加密函数上千条汇编无一条跳转(IDA F5 可直接编译),实为 MD5 F/G/H/I 四轮+T 表常数,但把 64 字节输入块变换当**分组加密器**用:key[8..24] 共16字节作状态,每轮更新,加密完回写 key。
- **级联结构**:用户名+密码合并填充至64字节(密码尾 0x80 固定、0x70=总长*8)→code 函数得 codeData→两块分别 XOR 0x36/0x5C(HMAC ipad/opad 特征)得 A1/A2→A1 填充后用原始密钥加密得 B1→服务器随机密钥用 B1 作 key 加密得 C1→B1 以 B2 为 key 加密,输出即登录包16字节密文。
- **识别要点**:shl/shr/xor/not 位操作密集+已知 MD5 T 表常数(-680876936、606105819)即 MD5 变体;XOR 0x36/0x5C 指向 HMAC 结构。
### 国服游戏封包解密-外挂制作全过程(路尼亚战记)
- 断点:OD bp send **按封包长度下条件断点**(`dword ptr [esp+0xc] == 0x0e` 打开武器铺的包长);send 缓冲区内存地址固定→对缓冲区下**硬件访问断点**→第二次 F9 直接落到加密 call;加密函数位操作/byte 操作密集,与普通函数风格不同(Thomasyzh)。
- 算法:逐字节 `imul 0x49; xor 0x15` 累加出表下标,查 0xc45878 处解码表(0xa7a9 大小)替换字节——查表置换型加密。
- 外挂:DLL 注入①hook ws2_32 send 抓特征包取 socket 句柄;②ReadProcessMemory 把解码表整表 dump 成文件;③裸函数 `mov ecx,表地址; call 加密函数` 主动调游戏内加密 call 后直接 send——**借刀加密**不必复现算法。
> 同法:wXgame上某游戏封包分析(rerefrancd)——x64dbg 按**发包函数特征码**(`8B 45 08 69 C0 D8 00...`,wsasend 返回几层定位)Ctrl+B 搜索;hook 加密函数(lazarus+detours)直接打印明文封包;包第3字节01=加密包/00=明文包;明文包字段对照出「强制pk」等逻辑漏洞封包,可远距离开仓库/强制pk。
### 韩服DNF二级密码封包解析
- 定位:多次 Sniffer 抓相同时段封包组对比;基础结构=2字节头(00+类型)/2字节长度(含头)/4字节参数;**关闭一切无关通讯**(关公告私聊、站仓库只剩 NPC)降噪再锁定二密包;二密是小游戏界面无 API 可断,用包内固定参数(00 00 00 78)在 send 第三参 lpbuf 设条件断点(tsgxyy)。
- 带壳:HS 保护+非通用壳→改版 OD 直接附加不脱壳;断点要快(服务器易判掉线),单步 30 秒内跑完,熟手直接翻堆栈拿返回地址。
- 加密:DES 对称;明文密码+服务器下发 index 从密钥组挑选密钥,加密后密文**更新并锁死**该槽位;伪造/损坏包服务端解不出 index 即拒。破解:hook recv 拿 index→hook memcpy 类内存传递定位 index 对应密钥组地址→一次拿全密钥→解密比对得明文。
### 逆向在线游戏加密通信协议(仿制服务端网关)
- 配置解密:服务器 IP 藏在加密配置(New.rst,长度16倍数)——API 监视工具(勾 Networking+ADVAPI32 加密 API)跑一遍流程,顺 connect 向上找加密调用,密钥/算法/block size 全在参数里照葫芦画瓢(usual)。
- 协议管线:dll 导入表函数名直接给出 `tryDeserializeIncomingPacket -> tryDeframeIncomingPacket -> Decrypt -> crc16 -> Decode`,按名字逐函数 IDA 分析;包结构:`923E(包头标识) + ServiceID(分发回调) + 包长度 + 0200(固定) + CRC16 + 包体 + EC3E(包尾)`。
- 包体 AES:解密函数名 `CRijndael::Decrypt`——Rijndael 即 AES,C++ 第三方组件名直接 Google 开源实现,MakeKey 初始化时一次调用(key 全局不变)照抄即可。
- **CRC16 的坑**:github 标准 crc16 结果对不上——查表算法**表不一样**;IDA dump 游戏自带 256 字节表替换进源码即对。
### 某P保护的一款音乐类PC游戏的分析之dump协议号
- 收发包对比:收包明文、发包加密(同序列两次抓包对比判定);包结构=4字节包长+未知数据+**协议号**+数据;在收包后 +0x4 处下断回溯处理函数,遍历调用点 dump 全部协议号枚举;某P(TP类)保护下仍可完成(少妇之友)。

### coco2djs手游封包协议分析jsc文件解密
- websocket 协议,charles 连不上登录服换 httpcanary;发送包部分明文、接收包大段乱码(压缩特征)(果冻大砍刀)。**jsc 解密捷径**:十六进制打开 cocos2djs.so 搜 ASCII `main.js`,附近 UUID 形字符串(`0ed68e2d-8b2f-4a`)即 xxtea key→jsc 解密 v1.44 工具直接解开;js 格式化后搜 `ws://`、`send`、`encrypt`、`encode` 定位编解码函数。

### 某淘X城镇unity应用协议分析

### 游戏协议大道-练气篇/筑基篇
- **练气(HTTP 登录层)**:JEB 搜登录 URL 字符串定位 sdkLogin→userpwd=DES(密码,"leiting" 固定密钥);key=MD5(`(username|userpwd密文|game%leiting%20210216)`)——密钥/盐/日期硬编码 java 层;登录只为拿 sid,sid 才是游戏真正账号(零加一)。
- **筑基(TCP 层)**:抓包可读性差似序列化 JSON→印证 **msgpack**(前6字节包头+4字节大端长度+msgpack 体,python msgpack.unpackb 验证);进游戏后包加密但 `cr` 两字符不变→拆包 lib{il2cpp,tolua,unity}.so=C#+u3d+lua 套路;assets/Lua_Android 文件头多11字节→AssetStudio 导出→lua 加密在 il2cpp.so 的 LuaEncryption,字符串搜出 key=`m71`,luac 用 luajit-decompiler 批量反编译。
- **AES key 来源推断**:加密 key=`服务端同步时间戳+"000000"` 恰16字节;顺第一个加密包向上找 `['sync_server_time',[1614052775]]` 包——**会话密钥由明文控制包下发**,抓握手序列即可捕获;标准 AES/ECB 无魔改,还原后可挤掉已登录会话。
### 某火热的区块链游戏(mir4)通信协议分析

### 迅雷协议分析
- 协议族:来源标识包→登录(QUERYAUTHEN+用户名+密码hash)→UDP PING 保活(用户id+标识串)→下载加积分(QUERYDOWNMESS+文件hash)→注销(QUERYLOGOUT);全部字段级结构已还原(长度/命令字/TLV 式 字段长+字段)(the0crat)。
- 密码 hash 非 MD5:跟 OD 定位到 0x40 长度填充(标准 MD5 是 0x38 起 64 字节块)——魔改 MD5,填充起始偏移变化;计数字段(包计数/登录计数)规律:首次登录+3 后续+4,下载首个文件+5 后续+1——多账号多次操作对比推出。

## 4. IM 与传统客户端协议
### QQ发送消息协议分析
- QQ 聊天走 UDP 4000→8000(双开则 4001);包结构:`02(起) + 版本2B + 命令2B(0016=发消息) + 序列2B + QQ号4B + TEA加密体 + 03(止)`;命令字段不加密,可作过滤判据(加百力)。
- **会话密钥链**:登录第6次认证(命令0022)由服务器下发,该包用**密码的两轮 MD5(16B)**加密——解聊天必须先有密码;解出的首字节 00+16字节会话密钥→用密钥 TEA 解密消息包,消息起点偏移固定、`20 00` 结束;工具链 Sniffer Pro 抓 CAP+QQDebugger(算 MD5/解密)+SmartConvert(文本转换)。
### YY登录协议流程解析
- 脱机协议:登录请求(RequestCode 0x1401 随机发5个IP)→版本校验(0x1501)→服务器回可用 IP/端口列表→取倒数第二个 IP 建 TCP(INightElf)。
- **混合加密握手**:客户端发 RSA 公钥对(n+e=03)→服务器用公钥加密 RC4 密码回传→此后全程 RC4;逆向捷径:netio.dll(IOCP)管理 socket,**断点下在「解密后和加密前」的函数**,密文明文一手掌握。
### 微信协议入门——原理篇
- 架构=**mmtls**(参考 TLS1.3)+protobuf:Handshake 协商密钥(1-RTT ECDHE/1-RTT PSK/0-RTT PSK;长连接用前两者,断连重连无 PSK 走 ECDHE、有 PSK 走 0-RTT)+Record 对称加密通信;业务数据 protobuf 序列化→压缩→业务层加密→mmtls 层加密(KongKong20);IDA 搜 "client hello"/"send client hello fail" 直接进握手代码,可读出 ClientHello 结构。

## 7. 网络层截包/发包工具与流量操纵
### 详解截取封包的原理

### 数据包伪造替换、会话劫持、https劫持之探索和测试

### 记对某校园APP的登入协议分析(公钥替换中间人)
- 登录流:请求公钥(带学校ID/设备ID)→服务端返回 1024 PKCS#1 PEM 公钥→密码 RSA 加密提交(AE86)。**中间人换钥**:自己生成密钥对→fiddler `bpu` 断住公钥接口→把响应里的公钥**替换成自己的**→客户端用你的公钥加密密码→你用私钥解出明文;无需逆向加密实现(RSA 填充的随机性使选择明文攻击不可行,换钥是正解);公钥有有效期,超时需重新走。
### 如何使用Wireshark解密Windows远程桌面(RDP)协议
- RDP over TLS→**mimikatz 导出服务器 RDP 私钥**:`crypto::certificates -systemstore:... -store:"Remote Desktop" /export`(密码 mimikatz)→openssl pkcs12 转 pem→Wireshark TLS RSA key list 配 IP/3389/**protocol=tpkt**→RDP 明文可读(连接序列穿 TPKT/X224/MCS/GCC 四层);可直看 CVE-2019-0708 的 MS_T120 虚拟频道触发点(肯特君)。
### ORACLE 10G 11G TNS协议DATA部分解析
- TNS DATA 内 SQL 提取:扫描 `0x0100` 特征→`0x01` 命令→长度字段(0xfe 长格式)→`0x0101` 后即 SQL 文本(去控制字符);代码级实现可直接用于数据库审计/SQL 注入流量监测(comeon)。
> 同法:网络安全分析之SMB协议(hanbingxzy 译)——SMB 会话结构/IPC$/ADMIN$ 共享/文件写入时序(Create→GetInfo→SetInfo→Write)威胁狩猎视角;windows smb协议简单分析(辑20)归此。

### 深思灵锐I协议分析(加密狗)

- 指令编码表(case 0..68: password/read/write/hmac 等)整理后可**模拟锁**;官方 bug:版本号 `==3.0.0` 才走高级 API,3.0.1 被当老版本处理。
