## TRW2000 / SoftICE 老工具独有手法(源自《01-Windows逆向/调试器与工具案例.md》原「六、」)

### SoftICE 技巧九则
作者:sharksing
- INIT 串超 128 字符:winice.dat 写两条 `INIT=` 分行;宏直接写 winice.dat(图形配置程序会吃引号导致宏坏)。
- `.` 回当前执行行,`.n` 回源码第 n 行;Ctrl+L 清窗碎片;Universal Video Driver 下 cmd→Alt+Enter 全屏→Ctrl+D 免重启切全屏。
- 下划线动态条件:`bpx eip if eax==_eax`(eax 再次等于当前值时断)、`bpx MessageBoxA if pid==_pid`(仅当前进程);修饰符 `bpx.t`(仅当前线程)/`.p`(仅当前进程)。
- `bpint 3 do "bc bpindex"` 一次性断点断后自删,防 int3 反调试;`G addr` 代替 BPX/BPM(反调试清断点法对一次性 G 无效)。

### SoftICE 宏定义集
作者:十夜
- 样例:`MACRO sname="s 0 l FFFFFFFF 'Tennight.C'"`(全内存搜)、`argdlg="D esp->c; p ret"`(GetDlgItemTextA 参数)、`argwin="D esp->8; p ret"`(GetWindowTextA)、`argreg="D ESP->14"`、`reg="bpx RegQueryValueExA IF *(ESP->8)=='%1' DO \"argreg\""`。
- 骨架:「断 API → `D esp->偏移` 看参数 → `p ret` 返回」;x64dbg 时代等价物=断点命令+表达式。

### SoftICE 断在第一条指令(壳程序入口三板斧)
作者:ljttt
①ProcDump 把入口 Section characteristics 改 E000020(可执行)后直接断 EP(对 Asprotect 无效);②EP 减一(Asprotect 恰好多留一字节),HIEW 写 0xCC,`I3HERE ON` 再 Load 即断在入口(完事 OFF);③源自 DOS4GW 时代 int3 入口法。

### TRW2000 小经验 + VB 符号调试
作者:令猪冲 / 小楼
- TRW:`bc` 可代 `bc*`;VB 程序不用预放 msvbvm6x.dll,browse&load 后直接 `bpx __vbastrcmp`;`ver blue` 护眼。
- VB 符号:`dbg2map.exe msvbvm60.dbg` → `msym.exe *.map` 产 .sym 放 TRW 目录自动载入(`sym` 命令切换);可对 exdec 反编译出的 VB P-Code 助记符直接设断(助记符名微软定的)。

### VMware 与 SoftICE 网络远程调试
作者:小四
- 显卡驱动装不下时走网络远程:虚拟机只留一块网卡;装 UND 通用网卡驱动(UNDSetup.exe,物理网卡"消失"正常,选 None 恢复);Initialization 写 `net start <本机IP> mask=... gateway=...; net allow <宿主机IP> auto password=xxx;X;`。
- 显示问题:.vmx 加 `svga.autodetect="FALSE"`+maxWidth/maxHeight/vramSize;用 symbol loader 的 Exports 预加载 user32.dll/mfc42.dll 才能按名 bpx。

### 修改 SoftICE 躲检测(2000/XP)
作者:佚名
- 改三文件(改完必须 LordPE 修 checksum 否则启动失败):NTICE.SYS——`"GFu*f"→"XFu*f"`(躲魔法串检测)、`\NTICE→\XTICE`、`Bchkd→Xchkd`(躲 BoundsChecker 后门)、`\Driver\NTice` 同步改、`Kernel32!UnhandledExceptionFilter→user32!MessageBoxExW`(躲部分 int3,代价 Faults On 失效);SIWVID.SYS、NMTRANS.DLL(`\\.\NTICE→\\.\XTICE`)同步改。
- 躲 INT1 检测:IDT 指令看 IDTBase,+0D 处 EE 改 8E(启动命令 `eb 8003F40D 8E` 自动化)。

### SoftICE Internals(命令表结构)
作者:佚名
- ComHandlerAddrTable(在 'A General Protection Violation...' 字符串下方)存所有命令处理例程地址;UserCommandRepository 存 `{char Com[n]; char Index;}` 双 0 结尾;FindCommand() 做串→索引——自制调试器命令解释器参照,也是给 SoftICE 加命令的 patch 点。
