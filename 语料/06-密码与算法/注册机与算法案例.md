## 一、注册机编写手法

### 教菜鸟写注册机(入门/中级/高级)
- 入门:W32Dasm 串式参考找错误提示→上溯关键跳转(jne 到失败分支)→从 `push ebp/mov ebp,esp` 函数头开始读;典型 CrackMe 算法 `for i: EAX=name[i]^(i+1); EBX+=EAX; 结果=EAX*6+(EBX<<7)` 再 `%lX` 格式化 lstrcmpA 比较,注册机 C 逐句照抄汇编(RoBa)。中级:多个局部变量分别计算后按 `"%lX%lu-%lu%lX-%lu%lu-%lX%lX"` 拼 8 段;字符小写转大写(`cmp 'a'/sub 0x20`)、相邻两字符 `(EBX+name[i])*name[i-1]` 滚动乘、`rol eax,1 ^ 0x1E240` 收尾;EDI 常量 0x64F4F0(版本常量)参与多段。高级:注册码长度约束藏在算式(`(len*3)<<2 + 0xCD == 0x1A5` 反解 len=18位)、逐位字符必须≥'0'、核心三段:查表取字符→LCG 迭代(`x=(x<<3)*0x12345+0x12345` 类)→与输入逐位异或后比较,只能逐位构造或穷举。技巧:CALL 先带过看返回值可疑(如返回用户名长度=4)再跟进;`[ebp+ecx-B8]` 寻址=取用户名第 ecx 字符的循环特征;wsprintf 格式串(`%lX`/`%lu`)直接暴露注册码组装格式。

### 注册码是怎样炼成的(明码与非明码)
- 明码比较:d 命令直接看到真码;非明码:逐位比较、一位错即跳走,必须逆算法写注册机。分析节奏:F8 过一遍 CALL 观察寄存器变色,值是地址就 d、是数值就比对输入长度/位数,先淘汰「装字符串/求长度/取 ASCII」类无用 CALL,再聚焦改变参与运算字符的 CALL(商朝子)。案例(中华压缩 7.0):关键 CALL 内 `esi = esi + 字符ASCII*6 + 0xA8` 逐字符累加,004f5003 的 CALL 对字符做合法性过滤(符合才置 al 非零、把字符存入 00D3B3C4),esi 结果转十进制=注册码后半部分,与前半拼接。

### 内存注册机的工作原理及masm源码
- 本质是超小调试器:CreateProcess 以 DEBUG 方式启动目标→在算出真码的地址写 INT3→WaitForDebugEvent 挂起→ReadProcessMemory/GetThreadContext 取真码显示;加壳目标同样适用(壳解压后代码落地址再下断)。骨架:
```asm
; (省略:CreateProcess(..., DEBUG_PROCESS, ...) 启动与 .while TRUE 外框)
.if DBEvent.dwDebugEventCode == EXCEPTION_DEBUG_EVENT && dword ptr [DBEvent.u.Exception.ExceptionRecord.ExceptionAddress] == 断点地址
    invoke ReadProcessMemory, pi.hProcess, 真码地址, addr buffer, len, NULL  ; 先恢复原字节/写 EIP-1
.endif
invoke ContinueDebugEvent, DBEvent.dwProcessId, DBEvent.dwThreadId, DBG_CONTINUE
```

## 二、注册算法通用模式与攻击面

### F(UserName)==G(SN) 注册算法
- 模式:程序把用户名算成中间码 F(Name),把输入的注册码也算成 G(SN),比较两个中间码——**不是拿 SN 与算出的码比,而是两侧各算再比**;攻击面:无需逆 F,只需构造一个 SN 使 G(SN) 落到 F(Name) 的值上,若 G 可逆则从中间码直接反解 SN;判别特征:验证函数里有两个对称的「计算 CALL」+一个比较 CALL(prince)。案例(Delphi 6 商业软件,ASPack 壳):6056C3 处 G(SN) 内部还有日期 2000-01-01 起的浮点天数参与(36526.0),注册码格式 `98765432101234567890a` 类;第二步再与当前时间浮点值比较判过期。
### 学注册机编写之 MD5
- 链:注册码小写转大写→用户名字母大写化→WideCharToMultiByte 宽转窄→**去掉用户名中的数字**(只留 a-z/A-Z)→与固定盐串 `f4hguNAg` 拼接→MD5;写码细节:盐是硬编码字符串,在解密函数附近搜宽字节能找到;去数字的过滤函数特征是 `cmp 'a'/'z'/'A'/'Z'` 四段判断后才写入目标缓冲(我是小三)。
> 同法:MD5算法注册算法研究、QQ 2005贺岁版登录口令加密算法
### 学注册机编写之查表
- ahead_dv 案例:关键 CALL 004158D0 里,用户名和注册码**先分别与同一张固定表(00433560 处字符串)比较**,即用户名/注册码前缀必须命中表项,再进 00415690 算法函数;查表型识别:验证函数入口成对出现「输入串 vs 固定地址串」的双循环比较;注册机=枚举合法前缀+实现后段算法(我是小三)。

## 八、老软件时代注册形态(辑1-5 综述)

- **明码/特征串时代**:winhex 9.x「找特征串几分钟搞定」,751E→EB22 一字节爆破即注册;注册码可以在 BBS 直接讨要;**算法开始出现**:UNFOXALL 查 18 字节 GBK 表异或、拼音加加注册表 BookID 查减法表、中华压缩逐字符 `esi+=c*6+0xA8` 累加、麻将拼图 wsprintf 多段拼装。
- **教学体系化**:KEYGENNING4NEWBIES #1-#7 国外 keygenme 教学套餐(MD5 入门到 ElGamal)、TMG Official Keygenme 系列练 miracl/freelip 大数库、CCG/BCG/FCG 组织化的破文流水线;**工具链**:TRW2000→OD 交替期、W32Dasm 串式参考、DeDe(Delphi)、MASM32 全手写注册机(信息技术教育考核/安全卫士均整源码直发)。
- **机器码绑定初现**:GetVolumeInformation 卷序列号方案成文,磁盘序列号加密是硬件指纹的起点;此后演进:内存注册机(KeyMake 思路)→IDA 抠代码→借 DLL→RSA 公钥替换→数据库/协议加密→APP 签名(见前七节)。

## 九、反破解设计(厂商视角,逆向者知彼)

### 设计一种注册验证算法模型
- 防爆破结构设计:注册标志分散多处、关键比较嵌套在业务逻辑、常量表+随机盐轮换。
